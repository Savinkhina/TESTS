# PERFORM
Оператор PERFORM в PostgreSQL (точнее, в его процедурном языке PL/pgSQL) нужен для того, чтобы выполнить запрос и отбросить его результат. Я бы сказала так: он выручает, когда вам важно выполнить действие (например, вызвать функцию с побочными эффектами — изменение данных, логирование, вызов процедуры), но сам результат (набор строк) вам не нужен. 
# Основные типы сканирования
- Sequential Scan (последовательное сканирование)
- Index Scan (индексное сканирование)
- Index Only Scan (исключительно индексное сканирование)
- Bitmap Scan (сканирование по битовой карте)
- TID Scan (TID / ctid сканирование)
- Seq Scan vs Index в контексте DWH
Как увидеть тип сканирования
EXPLAIN (ANALYZE, BUFFERS)
SELECT *
FROM sales
WHERE date >= '2024-01-01' AND city = 'MOW';
