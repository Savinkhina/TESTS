# PERFORM
Оператор PERFORM в PostgreSQL (точнее, в его процедурном языке PL/pgSQL) нужен для того, чтобы выполнить запрос и отбросить его результат. Я бы сказала так: он выручает, когда вам важно выполнить действие (например, вызвать функцию с побочными эффектами — изменение данных, логирование, вызов процедуры), но сам результат (набор строк) вам не нужен. 
# Основные типы сканирования
- Sequential Scan (последовательное сканирование)
- Index Scan (индексное сканирование)
- Index Only Scan (исключительно индексное сканирование)
- Bitmap Scan (сканирование по битовой карте)
- TID Scan (TID / ctid сканирование)
- Seq Scan vs Index в контексте DWH

Как увидеть тип сканирования
EXPLAIN (ANALYZE, BUFFERS)
SELECT *
FROM sales
WHERE date >= '2024-01-01' AND city = 'MOW';
# Триггеры
## По моменту срабатывания: BEFORE vs AFTER
- BEFORE — до сохранения строки. Можно менять NEW, отменять строку (RETURN NULL), делать проверки. Для DWH: нормализация, обогащение, контроль качества данных.
- AFTER — после того как строка уже записана. Менять строку нельзя, но можно делать побочные действия: логировать, обновлять агрегаты, слать уведомления. Для DWH: писать в таблицу истории изменений, обновлять материализованные представления, отправлять события в очередь.
## По уровню срабатывания: ROW vs STATEMENT
- FOR EACH ROW — функция вызывается для каждой строки. Подходит, когда нужна работа с NEW/OLD (нормализация, аудит, обогащение). Минус: при массовых вставках/обновлениях это дорого.
- FOR EACH STATEMENT — функция вызывается один раз на весь запрос. Нельзя обращаться к отдельным строкам, но можно сделать одну операцию на весь пакет: обновить счётчик, отправить одно уведомление, проверить бизнес-правило по всему набору.
## INSTEAD OF триггеры (для представлений)
- INSTEAD OF вешают на представления (VIEW) и используют, чтобы реализовать логику изменения данных через представление. Частый кейс: через представление разрешают UPDATE/DELETE, а внутри триггера реально меняют данные в базовых таблицах. В DWH такие триггеры используют редко, но они удобны, если нужно дать пользователям безопасный интерфейс к данным.
