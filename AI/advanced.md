# Метод k ближайших соседей (kNN, k-Nearest Neighbors)
## Как измерять расстояние
- Евклидово расстояние: a = (a₁, …, aₙ) и b = (b₁, …, bₙ): d(a, b) = √((a₁ − b₁)² + (a₂ − b₂)² + … + (aₙ − bₙ)²)
- Манхэттенское расстояние — сумма модулей разностей координат: d = |a₁ − b₁| + … + |aₙ − bₙ|. Так ходят по городу с прямоугольными кварталами.
- Расстояние Чебышёва — наибольший из модулей разностей. Для бинарных признаков (0/1) удобно расстояние Хэмминга — число несовпадающих позиций, а для текстов — косинусное расстояние, которое сравнивает направления векторов, а не их длины.
